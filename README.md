# cpe_two_star

Python solutions for CPE two-star programming problems. This repository is used to practice algorithmic problem solving, UVa-style input/output handling, and competitive programming techniques.

The problem list is based on the CPE Level 2 reference list:

- https://yuihuang.com/cpe-level-2/

## Repository Structure

Most files are standalone Python solutions. File names usually correspond to a problem number or an internal practice index.

```text
cpe_two_star/
├── 10003.py
├── 10352.py
├── 10360.py
├── 2-1.py
├── 2-2.py
├── 2-3.py
├── ...
└── README.md
```

## File Naming Rules

| Suffix | Meaning |
|---|---|
| `fast.py` | Faster or optimized solution. |
| `slow.py` | Slower solution, usually kept for comparison or testing. |
| `good.py` | Improved or cleaner accepted solution. |
| `plus.py` | Enhanced version or alternative improvement. |
| `other.py` | Alternative solution or different approach. |
| `bad.py` | Related to problematic or incorrect judge data. |
| `wrong.py` | Incorrect or experimental solution kept for reference. |
| `undone` | Problem not finished yet. |

## Requirements

- Python 3.x

No external packages are required for most solutions.

## Usage

Clone the repository:

```bash
git clone https://github.com/Ian684/cpe_two_star.git
cd cpe_two_star
```

Run a solution with standard input:

```bash
python3 10003.py < input.txt
```

Or enter input manually:

```bash
python3 10003.py
```

## Study Focus

This repository is useful for practicing:

- Dynamic programming
- Graph traversal
- Greedy methods
- Sorting and searching
- Simulation
- String processing
- UVa-style input parsing

## Notes

Some files may represent trial versions, slower versions, or unfinished solutions. When reviewing a problem, prefer files marked with `fast.py`, `good.py`, or `plus.py` when available.
